**Temuan produk yang dicatat, bukan diperbaiki (butuh keputusan pemilik):**

- **Nama tier tampil di UI ID.** `billing.plan.free` = "Paket Free" / `billing.plan.pro` = "Paket Pro" —
  token tier (`Free`/`Pro`) dipertahankan EN sebagai nama produk; deskriptor "plan" diterjemahkan.
  Bila pemilik ingin "Paket Gratis", itu keputusan penamaan produk (§5.6).
- **`Price / month` diambil dari mirror Stripe**; bila `priceCurrency` bukan IDR (mis. langganan lama
  USD), `formatCurrency` tetap merendernya apa adanya. D1 mengikat **pack kredit**, bukan langganan;
  guard langganan = keputusan produk terpisah.
- Label preset/`≈ (approx.)` dsb. sudah dibahas.
